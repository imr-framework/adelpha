# DELTA DIY MRI workshop

This section is for **workshop mentees**. You will work in Jupyter notebooks on a shared Git branch, then open a pull request so mentors can review your work.

| What | Where |
| --- | --- |
| Notebooks | [`console/notebooks/`](https://github.com/imr-framework/adelpha/tree/workshop/delta-2026/console/notebooks) |
| Branch | `workshop/delta-2026` (not `main`) |
| First step | [Repo setup](repo-setup.md) |

Start with [Repo setup](repo-setup.md): fork Adelpha with every branch, clone `workshop/delta-2026` from **your** fork, and open pull requests **into that branch**.
