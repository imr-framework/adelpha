Build a modern public marketing / documentation-landing website in Next.js for Adelpha.

================================================================================
PRODUCT CONTEXT (source of truth for copy)
================================================================================

Adelpha is “The Intelligent Magnetic Resonance Framework” — an observer GUI and digital-twin stack for MRI systems (Halbach / low-field focus), associated with the Geethanath lab / Adelpha brand.

Core product pieces:
1) Digital Twin UI (this desktop/web GUI)
   - Live thermal, B0, EMI, and RF telemetry
   - 3D magnet viewport (optional CAD/STL)
   - Live dashboard charts
   - Side panels: Telemetry, Agents chat, forecast, notes, raw sensors, CAD view
   - Console with Logging + Terminal
2) DTAM backend (separate Python repo)
   - Twin HTTP API (`make twin-api` → http://127.0.0.1:8080) — REQUIRED for telemetry
   - Agents API / Google ADK (`make agents-api` → http://127.0.0.1:8001) — OPTIONAL for Agents chat
3) Desktop packaging
   - Electron macOS builds exist (DMG/ZIP for Apple Silicon + Intel)
   - Linux / Windows installers can be represented with placeholder/dummy download links and install commands for now

The website is NOT the twin GUI itself. It should teach people what Adelpha is, how the infrastructure fits together, and how to download / install / run it.

Logo asset available in the twin UI repo at:
  public/logos/adelpha-gradient-logo.svg
Copy that (or a similar Adelpha mark) into the website’s public assets.

================================================================================
GOAL
================================================================================

Create a polished, tidy, impressive, easily navigable Next.js website where users can:
- Learn about Adelpha (vision, what it does, who it’s for)
- Understand the entire infrastructure (UI ↔ Twin API ↔ Agents API ↔ scanners/simulation)
- Download application binaries OR copy installation commands for macOS, Linux, and Windows
  - Most download URLs and package commands may be DUMMY / placeholder for now
  - UI must still feel real and production-ready (clear labels like “Coming soon” or “Preview builds” where dummy)
- Find docs-style explainers, architecture diagrams, and a clear “Get started” path

Tech: Next.js (App Router), TypeScript, modern CSS (Tailwind allowed if tasteful), deployable as a static/export-friendly or standard Next app.

================================================================================
DESIGN DIRECTION (IMPORTANT)
================================================================================

Make it modern, tidy, impressive — but NOT generic “AI SaaS slop”.

Hard design rules:
- One composition for the first viewport (not a dashboard)
- Brand first: “Adelpha” is hero-level, not a tiny nav word
- Expressive purposeful typography (avoid default Inter/Roboto/Arial/system stacks)
- Atmospheric background (subtle gradient/pattern/imagery) — not flat single-color only; not decorative-gradient-as-only-idea
- Full-bleed or edge-dominant hero visual; avoid inset media cards / collage clutter in the hero
- First viewport budget: brand, one headline, one short supporting sentence, one CTA group, one dominant visual — nothing else
- No floating badges/stickers/chips overlaid on hero media
- Default: no cards in the hero; cards only where they aid interaction (e.g. download OS picker)
- One job per section
- Prefer real product-feeling visuals (twin/magnet/console motifs) over abstract purple glow
- Ship 2–3 intentional motions (page load, scroll reveal, or hover) — presence, not noise
- Define a clear CSS variable color system
- Avoid: purple-on-white / purple-indigo AI themes; warm cream + terracotta serif broadsheet; dark-mode-by-default bias unless it truly fits; glow spam; rounded-full pill clusters; multi-layer shadows; emoji decoration
- Fully responsive: excellent desktop and mobile

Visual suggestion (not mandatory): deep space-black / cool glass / ice-cyan accents inspired by the twin UI’s live dashboard aesthetic (#03060a family, cool borders, restrained cyan), with strong brand typography.
